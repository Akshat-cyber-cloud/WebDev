### 🎵 Project 2 — Moodify

> **Suggests songs based on your real-time facial expressions using AI**

Moodify uses your device camera to detect facial emotions in real time via **Google MediaPipe**, then maps those emotions to curated music recommendations — no manual input needed. Just show your face, get your vibe.

```
😊 Happy    →  Upbeat & energetic tracks
😢 Sad      →  Calm & soothing melodies  
😠 Angry    →  High-energy & intense beats
😐 Neutral  →  Chill & lo-fi recommendations
```

### 🤖 Project 3 — Gauntlet AI

> **Two AI models enter. One answer wins. A third AI judges.**

Gauntlet AI is a multi-agent battle platform where two competing AI models go head-to-head on any question or challenge. An independent AI judge evaluates both responses across criteria like accuracy, clarity, and depth — then updates a live leaderboard with scores.

```
         ┌─────────────┐
         │  Your Query │
         └──────┬──────┘
                │
       ┌────────┴────────┐
       ▼                 ▼
  ┌─────────┐       ┌─────────┐
  │ Model A │       │ Model B │
  └────┬────┘       └────┬────┘
       │                 │
       └────────┬────────┘
                ▼
         ┌────────────┐
         │  AI Judge  │
         └─────┬──────┘
               ▼
        ┌─────────────┐
        │ Leaderboard │
        └─────────────┘
```

**Tech Stack**
